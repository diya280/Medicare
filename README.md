# Medicare

A full-stack healthcare management application built using the MEAN stack (MongoDB, Express.js, Angular, and Node.js).

## 🚀 Features

- User Authentication and Authorization
- Patient Management
- Doctor Management
- Appointment Management
- Medicine and Prescription Management
- Image Upload using Multer
- RESTful API Integration
- Responsive User Interface

## 🛠️ Technologies Used

**Frontend**
- Angular
- TypeScript
- HTML5
- CSS3
- Bootstrap

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- JWT Authentication

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/diya280/Medicare.git
cd Medicare
```

### 2. Setup Frontend

```bash
cd frontend
npm install
ng serve
```

### 3. Setup Backend

Open another terminal:

```bash
cd backend
npm install
npm start
```

Configure your environment variables in the backend `.env` file before starting the server.
